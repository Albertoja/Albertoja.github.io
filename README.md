# Alberto Espinosa Portfolio — Minimal version

Portfolio minimalista de una sola página.

## Cambios incluidos

- Estilo más limpio y menos grande.
- Header cambiado a "Alberto Espinosa Portfolio".
- Se ha quitado el teléfono.
- La primera sección ahora habla sobre el perfil, formación e intereses.
- Las habilidades aparecen antes de los proyectos.
- 4Below sigue destacado, pero con estructura más compacta.
- Mantiene estética oscura con tonos verdes.

## Archivos principales

- `index.html`
- `styles.css`
- `script.js`
- `/assets`

## Cambiar imágenes de 4Below

Sustituye los placeholders en `/assets` por imágenes o GIFs reales:

- `hero-4below.svg`
- `physics-ragdoll.svg`
- `procedural-map.svg`
- `enemy-ai.svg`

Si usas `.jpg`, `.png` o `.gif`, cambia también la ruta en `index.html`.

## Publicar en GitHub Pages

Sube el contenido del ZIP al repositorio `Albertoja.github.io`.

La raíz del repositorio debe contener:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`
